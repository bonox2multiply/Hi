## 로컬 검증

Node.js 22 이상에서 실행합니다. 빌드와 기본 테스트는 별도 패키지 설치 없이 실행할 수 있습니다.

```sh
npm run build
npm test
```

테스트 일부가 `dist/server/index.js`를 사용하므로 빌드를 먼저 실행해야 합니다.
`public/`은 화면, `worker/`는 서버 코드, `tests/`는 회귀 테스트입니다.
빌드 결과는 `dist/`에 생성됩니다.

## 운영 원칙

GitHub 코드를 기준으로 오류를 검토합니다. 확인된 오류만 최소한으로 수정하고 빌드 및 관련 테스트로 검증합니다. 디자인 변경, 새 기능과 사용성 개선은 적용 전에 사용자에게 보고합니다. 오류인지 불명확하면 먼저 보고합니다.

GitHub 업로드는 기존 Sites에 자동 배포되지 않습니다. 운영 반영 시 `.openai/hosting.json`의 기존 프로젝트를 유지하고 Sites 배포 절차를 사용해야 합니다. 비밀값과 인증 정보를 저장소에 커밋하지 않습니다.

## PR 검증과 승인

모든 PR에서 라벨과 변경 유형에 관계없이 GitHub Actions가 Node.js 22로
`npm run build`와 `npm test`를 순서대로 실행합니다. PR 생성·재개·코드 갱신 시
검사하며, 같은 PR에 새 실행이 시작되면 이전 실행을 취소합니다.

수정 작업뿐 아니라 검토·진단·보고에 필요한 빌드와 테스트도 별도 사용자
명령이나 승인 없이 수행합니다.

신규 기능, 리팩터링과 성능·사용성 개선은 구현 및 PR 생성 전에 사용자에게
보고하고 승인받습니다. 세부 작업 원칙은 [AGENTS.md](AGENTS.md)에 기록합니다.
검증 통과는 병합·배포 승인을 의미하지 않습니다.

## 경기 일정 다운로드

경기 센터에서 달력의 날짜를 누르고 **일정 파일 다운로드 (.ics)**를 선택하세요.
받은 파일을 개인 캘린더 앱에서 열어 경기 일정을 추가할 수 있습니다.

- KIA의 예정 경기 중 시작 시각이 확정된 경기만 지원합니다.
- 취소·중단·종료·진행 경기, 시간 미정, 오프라인 또는 갱신 지연 시 다운로드하지 않습니다.
- 마지막 조회 후 5분이 지났으면 정보를 새로고침해야 합니다. 클릭할 때 다시 확인합니다.
- 시간대 표시가 없는 공급자 시각은 기존 일정 화면 및 저장된 원본 자료와 같이 한국 시간으로 해석합니다.
- 파일에는 UTC로 저장하므로 캘린더 앱의 시간대 설정에 따라 표시됩니다.
- 종료 시각은 추정하지 않습니다. 다운로드한 일정은 변경·취소돼도 자동 수정되지 않습니다.
- 로그인·외부 캘린더 연동·알림·서버 저장은 없습니다.

## 브라우저에서 자동 확인하기

```sh
npm ci
npm run build
npm test
npx playwright install --with-deps chromium
npm run test:e2e
```

검사는 실제 빌드 결과를 로컬에서 열어 저장 기사, 뉴스 연결 실패와 재시도,
달력 키보드 조작, 일정 다운로드 및 제한 조건을 확인합니다.
PC 1280×900과 모바일 크기 390×844에서 Chromium으로 실행합니다.
모바일 크기 검사는 실제 휴대전화 검사를 대신하지 않습니다.
외부 API를 시험용 응답으로 대체하며 운영 데이터에 접근하거나 쓰지 않습니다.
서비스 워커와 실제 캘린더 앱 가져오기는 이 검사의 범위 밖입니다.

기존 Chromium을 사용해야 하는 환경에서는 해당 실행 파일을 지정할 수 있습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

PR 자동 검사에서도 빌드 → 기본 테스트 → 브라우저 검사 순서로 실행합니다.
브라우저 검사 실패 시 화면·실행 기록을 최대 7일 보관합니다.
`test-results/`, `playwright-report/`는 커밋하지 않습니다.


### 여러 경기 한 번에 받기

경기 센터 달력 위의 **예정 일정 한 번에 다운로드 (.ics)**를 누르면 조회 범위의
예정된 KIA 경기를 하나의 파일로 받습니다. 7일·30일 조회를 바꾸면 다운로드 범위도
바뀝니다. 버튼 아래에 실제 날짜 범위, 포함 경기 수와 제외 개수를 표시합니다.
선택한 날짜나 홈/원정 필터와 관계없이 해당 조회 범위 전체가 대상이며 시즌 전체는 아닙니다.
취소·종료·진행·시간 미정·범위 밖·중복 항목은 제외합니다. 더블헤더는 경기 ID가 다르면
각각 포함합니다. 다운로드할 경기가 없거나 정보가 오래됐거나 오프라인이면 파일을 만들지 않습니다.
개별 경기 다운로드도 계속 사용할 수 있습니다. 받은 일정은 자동 갱신되지 않습니다.

### 오프라인 저장과 버전 교체 검사

`npm run test:e2e`는 기존 화면 검사에 더해 실제 Service Worker를 사용하는
오프라인 화면 재열기, API 응답 캐시 제외, 이전 화면 캐시 교체를 검사합니다.
각 검사는 독립 브라우저 저장 공간을 사용하며 관련 없는 캐시는 유지되는지도 확인합니다.
`tests/browser/server.mjs`의 `test-previous` 응답은 로컬 검사 전용이며 배포 코드에 포함되지 않습니다.
외부 자료 연결은 이 검사로 확인되지 않습니다. 실제 제공처의 장애·제한은 별도로 확인해야 합니다.
